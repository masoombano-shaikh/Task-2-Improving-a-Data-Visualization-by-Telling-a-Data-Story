# README — Task-2: Improving a Data Visualization by Telling a Data Story

## Description
 This project evaluates the exploratory data analysis and visualizations created in the Python notebook for the Goodreads Books dataset. It critiques the original visualization approach, explains how the existing plots can be used for data storytelling, and assesses how design decisions affect the message communicated to the audience.
 The link to original Exploratory Data Analysis: https://www.kaggle.com/code/artist03/exploratory-data-analysis <br>
 The link to original Goodreads Dataset: https://www.kaggle.com/datasets/jealousleopard/goodreadsbooks


## Open the file on Mac
1. Download or copy `Task-2-exploratory-data-analysis_102303641.ipynb` to a local folder.
2. Open **Terminal**.
3. Navigate to the folder containing the notebook:
   ```bash
   cd /path/to/your/folder
   ```
4. Start Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
5. In the browser window that opens, select `Task-2-exploratory-data-analysis_102303641.ipynb`.

Alternative using JupyterLab:
```bash
jupyter lab
```

## Open the file on Windows
1. Download or copy `Task-2-exploratory-data-analysis_102303641.ipynb` to a local folder.
2. Open **Command Prompt**, **PowerShell**, or **Anaconda Prompt**.
3. Navigate to the folder containing the notebook:
   ```powershell
   cd C:\path\to\your\folder
   ```
4. Start Jupyter Notebook:
   ```powershell
   jupyter notebook
   ```
5. In the browser window that opens, click `Task-2-exploratory-data-analysis_102303641.ipynb`.

Alternative using JupyterLab:
```powershell
jupyter lab
```

## Install dependencies
The notebook imports these Python packages: `kagglehub`, `numpy`, `pandas`, `seaborn` and `matplotlib`.

### Using pip
```bash
pip install notebook jupyterlab kagglehub numpy pandas seaborn matplotlib
```

### Using conda
```bash
conda install pandas numpy scikit-learn seaborn matplotlib kagglehub -y
```

Note:
- `warnings` is a part of the Python standard library, so it does not need separate installation.
- `notebook` or `jupyterlab` may need to be installed if Jupyter is not already available.

## Run the notebook
After installing dependencies, launch Jupyter and run all cells from top to bottom, as indicated in the notebook instructions.
